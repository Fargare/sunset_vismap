# 🌅 夕日が見える場所マップ

日付をえらぶと、その日の**日の入りの方角**と、**太陽が水平線ぎりぎりまで見える場所**を地図の上に緑色で表示するWebアプリです。山や丘にかくれる場所は色がつきません。

▶ **アプリを開く**: `https://（ユーザー名）.github.io/（リポジトリ名）/`
（公開したあと、上のURLを自分のものに書きかえてください）

## つかい方

1. 見たい日をえらぶ
2. どんな夕日が見たいかをえらぶ（水平線ぎりぎり／赤い夕日が見えればOK／山が少しあってもOK）
3. 地図の緑の場所をタップすると、その場所の日の入り時刻や、Googleマップへのリンクが出ます

## しくみ（かんたんに）

1. 日付と場所から、太陽がしずむ**方角**と**時刻**を計算します。
2. 地図の各地点から、太陽がしずむ方角へ向かって地面の高さを調べ、いちばん高い山を見上げる角度を求めます。
3. その角度が小さければ「夕日が地平線近くまで見える」と判定し、緑色をつけます。

地球が丸いことによる「かくれ」と、大気による光の曲がりも計算に入れています。観測者の目の高さは1.6mです。

## 注意

- 日の入りの方角は、画面の真ん中の場所で計算しています。画面が広い（数十km以上）と、場所によって少しずれます。
- 地形だけで判定しています。**建物・木・雲・天気は考えていません。**
- 地形データの細かさには限りがあるため、小さな丘や崖は反映されないことがあります。実際に行くときは、現地でも確認してください。

## 公開のしかた（GitHub Pages）

1. このリポジトリに `index.html` と `README.md` をアップロードする
2. `Settings` → `Pages` → `Source` を `Deploy from a branch` にする
3. `Branch` を `main` / `(root)` にして `Save`
4. 1〜2分後、`https://（ユーザー名）.github.io/（リポジトリ名）/` で開けます
